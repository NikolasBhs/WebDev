Web Technologies

HTML

HTML, which stands for HyperText Markup Language, is the standard markup language used to create and structure content on the World Wide Web.

CSS

CSS stands for Cascading Style Sheets. It is a style sheet language used to define the visual representation , design, and layout of a document written in a markup language like HTML.

JavaScript

JavaScript (JS) is a lightweight, versatile programming language primarly known as the scripting language used to build interactive and dynamic web pages.

Bootstrap

Bootstrap is a free, open-source front-end framework used by web developers to build responsive, mobile-first websites quickly and efficiently.
